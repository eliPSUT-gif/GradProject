# Smart Academic Advisor Poster Image Generation Guide

Use this document as a creative brief for an image generation model to produce a polished project poster for **Smart Academic Advisor**.

## Project Identity

**Project name:** Smart Academic Advisor

**Core idea:** A web-based academic planning system that helps university students understand semester workload before registration. It evaluates course difficulty, predicts overall schedule risk, and gives explainable recommendations. Advisors can review student risk, and admins can manage users, transcript data, courses, and the scoring model.

**Main message:**  
Know your semester before you commit.

**Tone:** Modern, academic, trustworthy, intelligent, practical, clean, and data-driven.

## Poster Goal

Create a poster that communicates that this is a smart university advising platform, not a generic AI app. The poster should immediately suggest:

- students planning a semester schedule
- risk/difficulty scoring
- data-backed academic advising
- advisor/admin dashboards
- explainable recommendations
- a polished web application

## Recommended Poster Format

- **Orientation:** Portrait
- **Aspect ratio:** 4:5 or A3 vertical
- **Resolution:** High resolution, suitable for print and presentation
- **Style:** Premium university technology poster, clean dashboard aesthetic
- **Visual density:** Medium. It should feel informative but not crowded.

## Visual Direction

Use a modern academic tech design with:

- deep navy background or navy-to-white structured layout
- electric blue accents
- subtle grid lines or academic data patterns
- realistic or semi-realistic UI dashboard panels
- charts, semester cards, course tags, GPA bars, risk labels, and recommendation chips
- a student and advisor reviewing a semester plan, or a central laptop/dashboard scene

Avoid:

- cartoonish mascots
- random robot heads
- generic glowing AI brains
- cluttered floating icons
- overly dark cyberpunk style
- fake code-heavy visuals
- misleading medical/financial imagery

## Color Palette

Primary colors:

- Navy: `#0f1e3c`
- Deep blue: `#112b5f`
- Bright blue: `#2563eb`
- Light blue: `#8bc5ff`
- White: `#ffffff`
- Soft gray: `#f3f6fb`

Accent colors for risk:

- Green for easy/safe schedules
- Amber for balanced/monitor schedules
- Red for hard/at-risk schedules

## Main Poster Elements

The image should include these visual elements:

1. **Main title**
   - Text: `Smart Academic Advisor`
   - Make it large and clearly visible.

2. **Tagline**
   - Text: `Know your semester before you commit.`
   - Place under the title or near the main visual.

3. **Central product visual**
   - A polished dashboard interface on a laptop/tablet or floating UI panels.
   - Show a semester schedule with course cards.
   - Show a workload/risk score, such as `Balanced`, `Hard`, or `Risk 72/100`.
   - Show a small GPA or past-semester chart.

4. **Three user roles**
   - Student
   - Advisor
   - Admin
   - These can appear as small labeled sections, icons, or dashboard tabs.

5. **Feature callouts**
   Use short labels only:
   - `Course Difficulty`
   - `Semester Risk Score`
   - `Transcript Insights`
   - `Advisor Review`
   - `Admin Controls`
   - `Explainable Recommendations`

6. **Academic context**
   - Subtle university-style environment, classroom, campus silhouette, or clean study workspace.
   - Keep it background-level, not the main focus.

## Text Rules

The generated poster should not contain too much text. Keep text large and readable.

Preferred visible text:

- `Smart Academic Advisor`
- `Know your semester before you commit.`
- `Course Difficulty`
- `Semester Risk Score`
- `Advisor Review`
- `Admin Controls`

Do not generate paragraphs of tiny text. Do not invent university names unless specifically requested.

## Composition Suggestion

Top:

- Project name and tagline.

Center:

- Main dashboard/laptop visual.
- Include a risk meter, semester course cards, and GPA chart.

Bottom:

- Three role chips or columns: `Student`, `Advisor`, `Admin`.
- Small feature badges.

Background:

- Subtle navy academic grid, data lines, and soft blue lighting.

## Quality Checklist

Before accepting the image, check that:

- the project name is spelled correctly
- the tagline is readable
- the poster clearly looks like an academic planning/advising system
- the UI resembles a real dashboard, not random decoration
- Student, Advisor, and Admin roles are visible
- the color palette matches navy, blue, white, and soft gray
- the design is clean enough for a university presentation
- there is no excessive or unreadable generated text
