# 30-Second Promo Video Generation Prompt

Create a polished **30-second promotional video** for a university web platform called **Smart Academic Advisor**. The video should showcase the entire project in a clear, premium, academic, data-driven style. Match the same color scheme, typography feel, and visual identity as the provided project poster.

## Core Brand Direction

**Project name:** Smart Academic Advisor  
**Main tagline:** Know your semester before you commit.  
**Tone:** Modern, trustworthy, academic, intelligent, clean, practical, and professional.  
**Visual identity:** Premium university SaaS dashboard with deep navy backgrounds, white interface panels, bright blue highlights, soft shadows, and clear academic data visuals.

## Required Color Scheme

Use this palette consistently:

- Deep navy background: `#071f46`
- Darker navy: `#031834`
- Main blue: `#2563eb`
- Light blue accent: `#8bc5ff`
- Text navy: `#0f1e3c`
- White cards: `#ffffff`
- Soft gray panels: `#f3f6fb`
- Success green: `#10b981`
- Warning amber: `#f59e0b`
- Risk red: `#dc2626`

Avoid unrelated colors. The video should look like it belongs to the same product family as the poster.

## Overall Motion Style

Use smooth, elegant motion:

- soft fade-ins
- slide-up dashboard panels
- subtle scale-in for hero text
- animated chart bars
- score counters increasing numerically
- glowing blue accents
- clean transitions between scenes
- no shaky camera
- no chaotic effects

Keep the interface readable. Do not overload the screen with tiny text.

## 30-Second Timeline

### 0-5s: Hero Brand Opening

Show a deep navy background with subtle grid lines, faint academic data patterns, and soft blue glow. The **SmartAdvisor** logo appears first, then the title animates in:

**Smart Academic Advisor**

Under it, show the tagline:

**Know your semester before you commit.**

Use the same visual feeling as the poster: large white and light-blue title text, centered composition, clean spacing, subtle blue underline, and a professional academic tech mood.

The opening should instantly communicate that this is a smart university advising system, not a generic AI tool.

### 5-10s: Student Course Planning

Transition to a clean dashboard interface. Show a student planning a semester schedule.

Display a card titled:

**My Schedule Next Semester**

Inside the card, show course rows with realistic academic fields:

- Code
- Course
- Type
- Credits
- Difficulty

Example course rows:

- `11313` Algorithms Design and Analysis, Theoretical, 3 credits, difficulty `88`
- `11316` Theory of Computation, Theoretical, 3 credits, difficulty `91`
- `11323` Database Systems, Theoretical, 3 credits, difficulty `62`

Animate the course rows entering one by one. Difficulty badges should use amber/red colors depending on difficulty. Add a small label:

**Plan before registration**

The viewer should understand that students can build and evaluate a schedule before committing.

### 10-15s: Difficulty Meter And Explainable Recommendations

Show a large **Difficulty Meter** card beside the schedule. Animate a numeric score counting upward to something like:

**83 / 100**

Show the risk label:

**Hard**

Use a horizontal meter from green to amber to red. The pointer should land in the red/hard area.

Below or beside it, show a card titled:

**AI Recommendations**

Animate three recommendation lines:

- Consider replacing one hard course with a lighter elective.
- Move one theory-heavy course to a future semester.
- Add one low-workload course to balance the schedule.

Also show a small section titled:

**Notes & Rationale**

Use short explanation chips like:

- Theory-heavy workload
- Maximum credit load
- Similar content overlap

This scene should make the system feel explainable, not like a black-box score.

### 15-20s: Transcript And GPA Insights

Transition to academic history and transcript intelligence.

Show a clean transcript panel with semester rows sorted clearly in academic order:

- Fall 2023
- Spring 2024
- Summer 2024
- Fall 2024
- Spring 2025

Show pass/fail status badges and marks out of 100, with **50/100 counted as passed**.

Beside it, show a **Past Semester GPA** bar chart. Animate the bars rising from left to right in semester order. Make the labels readable and correctly ordered by semester, not by GPA value.

Include short text:

**Transcript insights that support better planning**

This scene should communicate that the project uses academic history, GPA trends, and transcript data to support schedule decisions.

### 20-25s: Three Roles, One Smart System

Show three polished role cards, matching the poster:

**Student**

Plan your semester, evaluate workload, and get smart recommendations.

**Advisor**

Review student schedules, identify risks, and advise with confidence.

**Admin**

Manage users, courses, transcript data, and model controls.

Each role card should include a simple white line icon inside a blue circular badge. The cards should slide in one by one from left to right. Use vertical dividers or soft card separation like the poster.

This scene should show that the platform supports the full academic advising workflow, not only the student dashboard.

### 25-30s: Final Product Value And Closing

Return to a strong branded closing screen with a deep navy background, the SmartAdvisor logo, and a polished dashboard glow behind it.

Show these final lines:

**Smart Academic Advisor**

**Data-driven. Explainable. Built for better academic decisions.**

Then end with:

**Plan smarter. Advise faster.**

Keep the closing clean, confident, and memorable. Use a subtle blue glow and a final fade-out.

## Required Feature Coverage

The video must visually communicate these project features:

- role-based login and dashboards
- student semester planning
- course difficulty scoring
- full schedule workload/risk evaluation
- explainable AI-style recommendations
- transcript and GPA insights
- advisor review of student risk
- admin user/course/data management
- clean Supabase-backed academic data feel

## UI Style Requirements

All interface panels should look like a real web app:

- white rounded dashboard cards
- thin gray borders
- soft shadows
- navy text
- blue icons and headings
- readable tables
- clear badges
- professional spacing

Do not show random fake UI. Every screen should look connected to the Smart Academic Advisor product.

## Text To Include

Use only short, readable text. Include:

- `Smart Academic Advisor`
- `Know your semester before you commit.`
- `My Schedule Next Semester`
- `Difficulty Meter`
- `83 / 100`
- `Hard`
- `AI Recommendations`
- `Past Semester GPA`
- `Student`
- `Advisor`
- `Admin`
- `Data-driven. Explainable. Built for better academic decisions.`
- `Plan smarter. Advise faster.`

Avoid long paragraphs and tiny unreadable filler text.

## Negative Prompt

Do not include cartoon robots, AI brains, cyberpunk hacker visuals, messy neon scenes, random university logos, unrelated mascots, fake medical or financial symbols, childish graphics, cluttered UI, misspelled words, tiny unreadable text, distorted typography, excessive lens flares, stock-photo people, random code screens, or colors that do not match the navy/blue/white project palette.

## Final Output Requirements

- Duration: exactly 30 seconds
- Aspect ratio: 16:9
- Resolution: 1920x1080
- Style: modern academic SaaS promo
- Motion: smooth, professional, readable
- Color scheme: same as the poster and project UI
- Main purpose: quickly show the project’s value and major features
